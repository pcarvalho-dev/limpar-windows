🎨 VERSÃO COM INTERFACE GRÁFICA
--------------------------------
Esta é a versão GUI moderna do sistema de limpeza do Windows!

✨ Características:
  • Interface gráfica moderna com tema escuro
  • Design intuitivo e profissional
  • Checkboxes visuais para cada opção
  • Barra de progresso em tempo real
  • Log colorido de execução
  • Arquivo executável único (.exe)
  • Não precisa instalar Python!

📦 ARQUIVOS DISPONÍVEIS
-----------------------
  📁 Versão CLI (Terminal):
     • limpar_windows.py - Script Python CLI
     • Limpeza Windows.bat - Executar CLI
     • README_LIMPEZA.txt - Manual CLI

  💻 Versão GUI (Interface Gráfica):
     • LimpezaWindows.exe - Executável GUI (ÁREA DE TRABALHO)
     • limpar_windows_gui.py - Código fonte GUI
     • README_GUI.txt - Este arquivo

🚀 COMO USAR - SUPER FÁCIL!
---------------------------

OPÇÃO 1 - Executável (Recomendado):
  1. Clique duplo em: LimpezaWindows.exe (na área de trabalho)
  2. ⭐ ACEITE as permissões de Administrador (SEMPRE solicita)
  3. Marque as opções que deseja limpar
  4. Clique em "🚀 INICIAR LIMPEZA"
  5. Aguarde a conclusão

  ⚡ IMPORTANTE: O executável SEMPRE roda como Administrador!
     → Você verá o UAC (Controle de Conta de Usuário)
     → Clique "Sim" para continuar
     → Isso garante 100% de eficiência na limpeza!

OPÇÃO 2 - Python (se tiver instalado):
  1. Execute: python limpar_windows_gui.py
  2. Siga os passos acima

🐛 SOLUÇÃO DE PROBLEMAS
-----------------------

"Windows protegeu seu PC"
  → Solução: Clique em "Mais informações" → "Executar assim mesmo"
  → Motivo: Executável não tem assinatura digital
  → Seguro: Sim! Código aberto em limpar_windows_gui.py

"O executável não abre"
  → Solução: Clique direito → "Executar como administrador"
  → Verifique se Windows Defender não bloqueou

"Erro de permissão durante limpeza"
  → Solução: Execute como Administrador
  → Feche programas que podem estar usando arquivos

"Docker: Nenhum espaço liberado"
  → Normal se não tiver containers/imagens não usados
  → Docker só remove recursos órfãos

Interface parece pequena/grande
  → Solução: Configurações de DPI do Windows
  → Janela é fixa em 900x750 pixels

🎁 EXTRAS
---------

Tamanho do Executável:
  • LimpezaWindows.exe: ~15-20 MB
  • Inclui Python e todas dependências
  • Não precisa instalação

Localização dos Arquivos:
  • Desktop: LimpezaWindows.exe (executável)
  • C:\Users\pablo: Código fonte e scripts
  • C:\Users\pablo\dist: Pasta de compilação

Recriar o Executável (se modificou o código):
  1. Edite: limpar_windows_gui.py
  2. Execute: pyinstaller --onefile --windowed --name="LimpezaWindows" limpar_windows_gui.py
  3. Novo .exe em: dist\LimpezaWindows.exe
