VERSÃO GUI (RECOMENDADA):

  1. Vá para a ÁREA DE TRABALHO
  2. Clique duplo em: LimpezaWindows.exe
  3. ⭐ Aceite as permissões de Administrador (UAC)
  4. Marque as opções e clique "INICIAR LIMPEZA"

  Pronto! ✅

VERSÃO CLI (ALTERNATIVA):

  1. Vá para a ÁREA DE TRABALHO
  2. Clique duplo em: Limpeza Windows.bat
  3. Digite números para marcar, ENTER para confirmar

  Pronto! ✅

  🐛 PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════════════════

❓ "Windows protegeu seu PC" ao abrir .exe
   → Clique "Mais informações" → "Executar assim mesmo"
   → Normal! Executável sem assinatura digital
   → Totalmente seguro! Código aberto disponível

❓ Versão CLI não abre
   → Você precisa ter Python instalado
   → Use a versão GUI (.exe) - não precisa Python!

❓ "Erro de permissão" durante limpeza
   → Execute como Administrador
   → Feche programas que podem estar usando arquivos

❓ Pouco espaço liberado
   → Normal se seu PC já estava limpo
   → Tente executar mensalmente

❓ Navegador não limpou
   → Feche TODOS navegadores antes de executar
   → Navegadores bloqueiam acesso ao cache quando abertos
